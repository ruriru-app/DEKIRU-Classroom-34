# Interview Activity：今後の拡張要望

記録日：2026-09-19。作成画面の左右プレビューと左メニューの単語分類は実装済み（検証・公開状況は引き継ぎ文書を参照）。回答カードを使った複数分類は未実装の将来仕様として記録する。

## 作成画面とプレビュー

- 左側で活動を編集し、右側の広いエリアで教師用・児童用ページを確認したい。
- 各入力項目が誰向けで、どこに表示されるかを明確にする。「説明」を児童向けに書いたのに教師側にしか出ない、といった混乱を避ける。
- 保存用の名前、活動タイトル、児童向け説明、教師用メモを区別する案。具体的な項目構成と既存データの扱いは実装時に整理する。

## 左メニューの単語選択（追加要望）

- 既存のUnitページと同じように、カテゴリーごとの枠を縦に並べ、開閉できる形式にする。
- カテゴリー単位で一括選択・解除でき、カテゴリー内の個別語句はカプセル全体をクリックして選択・解除する。
- 3・4年生だけでなく5・6年生の活動も同じ作成画面で作る。特定学年の単語だけに限定しない。
- 単語の分類はデータベースの「スタンダード／プラス」に合わせる。参考画像の Basic / Advance をそのまま採用するのではなく、データベースの分類を基準にする。
- カテゴリー名・分類・語数を分かりやすく表示する。既存の選択済みカードはレイアウト変更で失わない。

## 回答カードを使った複数分類

現在の Yes / No は試作の第一段階。将来は `What color do you like?` のような、複数の回答先がある質問にも対応したい。

### ユーザーの希望

- 回答エリアを、指定した縦（行数）・横（列数）のマスに分ける。
- 各マスに、回答になり得る Picture Card を並べる。
- 用意したカード以外の回答を受けられるよう「＋その他」を用意する。
- インタビュー相手の名前タイルを回答に対応するマスへ振り分ける。

### 既存機能との整合性

- 基本操作は現在と同じ「名前（または番号）を選択 → 回答先をタップ」。出席番号のみの利用も維持する。
- 回答の変更、未実施へ戻す操作、各回答先の人数表示も維持する。
- Yes / No を置き換えるのではなく、複数分類にも対応する拡張として扱う。
- 保存・再開・将来の提出用成果物にも、回答カードと分類結果の対応を保持する。

### 実装時に具体化する点

- 「＋その他」が一つの共通回答先なのか、押すと新しい回答マスを追加するのかは未確定。ユーザーの表現を勝手に限定しない。
- 回答カードの指定方法、行列数とカード数の関係、縦画面・横画面での収まりを整理する。
