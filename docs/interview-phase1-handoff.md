# Interview Activity — 第１工程

## 今回の範囲

既存Gamesの「Create Games」でInterviewプリセットを作成・編集・削除し、UnitのActivitiesから教師が名簿を準備してURL配信できます。児童側は受信内容の確認用仮画面までです。第２工程の文章作り・Interview Sheet、第３工程のPDF提出は未実装です。

一般公開用カタログは空です。「Colorsサンプルを作成」を押して保存したものだけが、そのブラウザ内で利用できます。保存やJSONの取得は公開ではありません。GitHubへはまだ送信していません。

## 確認の流れ

1. Games → Create Games → Interviewを作る。
2. 「Colorsサンプルを作成」で9色、`Do you like (P)?`、YES／NO、Let’s Try 1 Unit 4が設定されます。確認後「プリセットを保存」。
3. 同じブラウザのLet’s Try 1 Unit 4 → Activities → Colorsを準備。作者の保存リストから「教師画面で試す」でも開けます。
4. 「クラスを登録・編集」またはヘッダーの設定からクラス設定を開きます。クラス名を入力し、Excel等から「出席番号／苗字（漢字）／名前（漢字）／苗字（ひらがな）／名前（ひらがな）／苗字（英語）／名前（英語）」の7列を貼り付け、「名簿を確認」して保存します。使わない表記も列は空欄で残します。1～100人、出席番号は必須・重複不可です。
5. 教師画面に戻ってクラス、名前の表記、苗字＋名前／名前のみを選びます。番号は必ず表示します。同名は番号で区別します。選択した表記の必要欄が空なら設定で補完してください。
6. 名簿入りURLの共有に関する注意を確認し「この内容で配信」。既存のURLコピー・QR・試す画面が開きます。
7. 別ブラウザでも受信仮画面で質問・カード数・回答エリア・人数を確認できます。

## 制約・個人情報

- クラス設定追加：名簿の全表記はブラウザ内にのみ保存し、配信URLには選択した表示名・出席番号・児童IDだけを含めます（クラス名・プリセット等の配信情報は従来どおり）。これはアクセス制限ではありません。
- クラスは設定で編集します。別タブで名簿が変更された場合、教師画面の共有同意は解除されます。配信直前にも保存内容を再確認します。
- 旧名簿は読み込むだけでは変更しません。苗字と名前は自動分割せず、旧氏名を見ながら必要な表記を補完します。v2初回置換前の保存データは `dekiru-class-rosters-backup-v1` にバックアップします。旧データに番号がない場合は新規配信前に補完が必要です。発行済みURLの読み込みは維持します。

- プリセットと名簿は同一端末・ブラウザ・オリジン内に保存します。自動同期はありません。
- URLに名簿が含まれます。暗号化や閲覧制限はなく、URLを知る人が読み取れます。クラス内でのみ共有してください。
- QR容量を超える場合はURLコピーを利用できます。コピー機能が使えない場合は文字列を選択して手動コピーできます。
- PC内のfile URLは他端末へ配布できません。ローカル確認用HTTPのlocalhostも学校の別端末には配れません。実際の配布は公開後のURLを使用します。
- 作者画面には認証がありません。サブスク・パスワード・ログイン機能は今回の対象外です。
- 公開依頼用JSONはプリセットのみです。名簿を含みません。

## 追加したデータ構造

- InterviewPreset v1: ID、表示名・タイトル、説明、複数Unit割り当て、固定文または単一 `(P)` テンプレート、既存カードID、可変数の回答エリア、作成・更新日時。
- ClassRoster v1: クラスID、クラス名、安定した児童ID・任意番号・名前、作成・更新日時。同名の児童も別々に保持します。
- ClassRoster v2: ローカル保存用。必須の出席番号と `names.kanji/hiragana/english` 各 `family/given`、任意の `legacyName` を保持。配信前にv1名簿へ変換し、未選択の氏名を除外します。
- InterviewDelivery v1: 配信ID、配信日時、Presetの独立コピー、名簿の独立コピー。発行後の編集は既存URLに反映しません。
- 保存キー: `dekiru-interview-presets-v1` / `dekiru-class-rosters-v1`。既存ゲーム保存キーとは分離しています。

## 次工程への接続点

### 配信リンクの有効期間（2026-09-19）

- 新規配信は1・4・12・24時間から選択、初期値1時間。配信ボタンを押した時に開始し、教師画面と共有ダイアログに終了日時を表示します。
- 配信データv2にexpiresAtを追加。旧v1リンクは期限なしで読み込み、新しいリンクを古い受信コードが期限なしとして扱わないようv2を使用しています。
- 受信画面は期限ちょうどで内容を消して「活動時間が終了しました」を表示。開いたままのタイマーとfocus/pageshow/visibilitychangeで確認します。第2工程でもこの期限判定を維持してください。
- 端末時計に基づく表示制限です。URL内のデータ削除や認証ではありません。説明は「リンクについて」にまとめ、主画面では必要最小限の名簿とクラス内共有を案内します。
- テスト駆動で期限境界・4択・開いたまま・再読込・復帰イベント・旧URL・不正URLを検証。全37テストファイル成功、公開用出力でも期限・クラス配信・統合ブラウザテスト成功。独立レビューの未解決指摘なし。
- 実機のスリープ復帰・タッチ、本番配信、後続の児童活動は未検証または範囲外。既存URLへの期限の後付けはせず、必要な場合は再配信します。GitHubには未公開です。
